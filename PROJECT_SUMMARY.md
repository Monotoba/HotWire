## 🚀 Installation Methods

### 1. Automated Installation (Recommended)
```bash

./install.sh          # Linux/Mac
install.bat           # Windows
```

### 2. PyPI Package (Professional Distribution)
```bash
pip install wire-temperature-calculator
wire-temp-calc --help
```

### 3. GitHub Releases (Executable Packages)
- **Windows**: `WireTemperatureCalculator-Windows.zip`
- **macOS**: `WireTemperatureCalculator-macOS.dmg`
- **Linux**: `WireTemperatureCalculator-Linux.AppImage`

### 4. Manual Installation
```bash
# Professional development setup
python3.13 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m wire_temp_calc.main
```
