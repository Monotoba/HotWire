# Project summary

HotWire is an alpha wire-temperature estimation application with CLI and PySide6 GUI. Current features and installation instructions are in the [README](README.md) and [user guide](docs/user-guide.md). The [model validation note](docs/model-validation.md) lists assumptions and unresolved safety and measurement work. See the [release checklist](docs/release-checklist.md) for the actual release state.
